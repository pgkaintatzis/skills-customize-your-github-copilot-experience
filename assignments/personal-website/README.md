# 📘 Assignment: Interactive Personal Website

## 🎯 Objective

Build an interactive single-page portfolio website that showcases your skills and projects. You'll learn how to structure web pages with HTML, style them with CSS, and add interactivity with JavaScript.

## 📝 Tasks

### 🛠️ Task 1: Create the HTML Structure

#### Description
Create a well-organized HTML page with multiple sections: a navigation bar, hero section, about section, projects gallery, and contact section. Use semantic HTML elements to structure your content.

#### Requirements
Completed program should:

- Include `<header>` with navigation links to all sections
- Have a hero section with a welcoming title and subtitle
- Include an "About" section with a brief bio
- Have a projects gallery section with at least 3 project cards
- Include a footer with contact information
- Use semantic HTML5 elements (`<nav>`, `<section>`, `<article>`, `<footer>`)

### 🛠️ Task 2: Style with CSS

#### Description
Create an attractive, responsive design using CSS. Make your portfolio visually appealing with colors, typography, spacing, and a consistent layout. Ensure the design works on both desktop and mobile devices.

#### Requirements
Completed program should:

- Use a cohesive color scheme (at least 3 colors)
- Style navigation to be clearly visible and distinguishable
- Format text with appropriate font sizes and weights for readability
- Use flexbox or grid to organize project cards
- Include hover effects on interactive elements (links, buttons, cards)
- Be responsive: adapt layout for mobile devices using media queries

### 🛠️ Task 3: Add Interactivity with JavaScript

#### Description
Add JavaScript functionality to make your portfolio interactive. Implement smooth navigation, form validation, and dynamic content effects.

#### Requirements
Completed program should:

- Implement smooth scrolling when clicking navigation links
- Add a functional contact form with validation (required fields, email format)
- Display form submission feedback (success/error message)
- Include at least one interactive element (e.g., toggle menu, image gallery navigation, theme switcher)
- Log form data to the console when submitted

### 🛠️ Task 4: Polish & Deploy (Stretch Goal)

#### Description
Enhance your portfolio with advanced features and prepare it for sharing.

#### Requirements
Completed program should:

- Add animations to elements as they scroll into view (using CSS or JavaScript)
- Include a working contact form that either submits data or displays a success message
- Add a dark mode toggle that persists using browser storage
- Deploy your website using GitHub Pages or another hosting service
- Include meaningful comments explaining key JavaScript functions
